# 负载均衡验证步骤

我们已经成功实现了**负载均衡**功能！
*   创建了 `LoadBalance` 接口，并实现了 `RandomLoadBalance` (随机) 和 `RoundRobinLoadBalance` (轮询)。
*   修改了 `ZkServiceDiscovery`，现在它会返回所有可用的服务地址列表，而不是只返回一个。
*   修改了 `NettyClient`，让它在拿到地址列表后，使用 `LoadBalance` 策略选出一个地址。

现在，我们来进行**多实例验证**，看看是不是真的能负载均衡。

### 验证步骤：

1.  **启动第一个服务端**
    *   运行 `ServerBootStrap.main()` (监听 7000 端口)。
    *   等待控制台输出 `Register service: ...`

2.  **启动第二个服务端**
    *   运行 `ServerBootStrap2.main()` (监听 7001 端口)。
    *   等待控制台输出 `Register service: ...`

3.  **启动客户端验证**
    *   运行 `ClientBootStrap.main()`。
    *   **观察控制台**：你应该能看到类似 `负载均衡选择了X服务器` 的日志。
    *   **多次运行**：多运行几次客户端（比如 5-10 次）。
    *   **预期结果**：你会发现请求会随机（或轮询）打到 7000 和 7001 两个端口上，而不是只盯着一个打。

---

### 💡 如何切换策略？
目前默认使用的是 **随机策略 (Random)**。如果你想试试 **轮询 (RoundRobin)**：
1.  打开 `NettyClient.java`。
2.  找到第 31 行：
    ```java
    private static LoadBalance loadBalance = new RandomLoadBalance();
    ```
3.  改成：
    ```java
    private static LoadBalance loadBalance = new RoundRobinLoadBalance();
    ```
4.  重新运行客户端验证。
