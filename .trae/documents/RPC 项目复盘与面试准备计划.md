# RPC 项目复盘与面试准备计划

太棒了！我们现在进入项目的“收官阶段”。这一步至关重要，因为**代码写得再好，如果讲不出来，在面试官眼里等于没写**。

我们将通过三份核心文档，帮你把这个项目完全“吃透”，并转化为简历上的战斗力。

## 1. 项目说明书 (README.md)
*   **目的**：让面试官或 HR 打开你的 GitHub 仓库时，第一眼就被惊艳到。
*   **内容**：
    *   **架构图**：清晰展示 5 层架构（服务层、代理层、注册层、协议层、传输层）。
    *   **特性列表**：列出所有牛逼的功能（SPI、自定义协议、心跳、Spring 集成）。
    *   **快速开始**：让别人能把代码跑起来。

## 2. 简历描述模版 (Resume.md)
*   **目的**：直接复制粘贴到你的简历上，用词专业、精准。
*   **策略**：使用 STAR 法则（情境、任务、行动、结果），突出**解决了什么难点**。

## 3. 面试题库 (Interview_QA.md)
*   **目的**：预判面试官的预判。
*   **覆盖范围**：
    *   **Netty 相关**：粘包拆包怎么解？ByteBuf 怎么用？
    *   **序列化**：为什么不用 Java 原生序列化？SPI 是怎么实现的？
    *   **分布式**：ZK 挂了怎么办？负载均衡怎么做的？
    *   **Spring**：BeanPostProcessor 的原理是什么？
